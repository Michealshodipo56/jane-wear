# Jane Wears — The Living Atelier

Implementation authorized by the user's instruction to proceed.

Bodoni Moda display type with Manrope interface text. Ivory #F5F0E7, obsidian #171411, bronze #AD8255, stone #D8C9B8. A twelve-column editorial rhythm, oversized HTML wordmark behind the transparent model, fine seam-like rules, asymmetrical photography and generous margins. The gown supplies the expressive color.

Narrative: statement, studio introduction, interactive collections, craftsmanship, inspiration lookbook, bespoke invitation and final contact statement. Shared page layouts extend this direction into services, atelier, garment details and forms.

Signature interaction: a four-stage outfit request with image previews, validation and review. No delivery destination is supplied, so requests are downloadable drafts, explicitly not submitted. Appointment times are preferences, not confirmed availability.

Motion: restrained text reveals, image reveals and fade/rise transitions; GSAP hero entrance and scroll reveals, with reduced motion and mobile parallax disabled.

Assets: supplied generated transparent hero and four sourced Ankara stock photographs. Stock images are inspiration, not claimed portfolio. Missing: authentic designer portrait/biography, original garment photographs, contact channels, calendar availability and form delivery backend.

Stack: Next.js App Router, TypeScript, Tailwind CSS and GSAP, static export. Native accessible controls and browser dialogs where appropriate. No invented contact details or credentials.
