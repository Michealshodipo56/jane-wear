# Jane Wears — The Living Atelier

Next.js App Router, TypeScript, Tailwind CSS and GSAP. Static export for Sites hosting.

Run `npm install`, then `npm run dev`. Production: `npm run build`. TypeScript: `npm run typecheck`. Build output is `out/`.

The hero is an AI editorial concept. Lookbook images are licensed stock inspiration; credits live in `assets/images/SOURCES.md`. Replace them with authentic work before presenting a commissioned portfolio. Garment entries are maintained in `app/data.ts`.

Request, contact, and appointment forms download unsent JSON drafts. No personal information or reference photos is transmitted or persisted. Image previews last for the browser session; draft exports list filenames only. Production delivery needs a configured backend or verified delivery destination, upload storage if required, and appropriate privacy copy. Dates and times are preferences, not confirmed availability.
